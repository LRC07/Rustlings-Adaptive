选题：Rustlings-Adaptive —— 自适应 Rust 学习 Agent

Rust 的所有权、生命周期、泛型、trait 等概念仅靠文档难以内化，社区公认
上手最快的方式是 rustlings 这类填空练习：给一段故意写残的代码让学习者
补全，由编译器与测试当场判对错。但 rustlings 题目固定、不区分基础与
短板，也不记录学习者的错误，无法定向巩固。

直接让通用 LLM 出题同样不可靠：生成的代码常含语法或类型错误，不保证可
编译；不了解学习者的历史错误，出题泛泛；也不会在本地实际运行验证题目
可解。根本原因在于，通用 Agent 既缺持久状态，也无法可靠地在本地执行
与校验代码。

本项目旨在做一个自适应 Rust 学习 Agent，将 rustlings 式填空作为入口
之一，形成“练—评—记”闭环。核心流程为：依据薄弱知识点生成填空题（含
todo、测试、参考解）→ 本地用 rustc --test 做“能编译 / 参考解全绿 /
todo 模板必失败”的三重校验，不通过自动重生成 → 学习者在 CLI 中做题
并获实时反馈 → 采集编译错误与 panic，归入错误画像与错题本 → 据此定向
再出题。

与通用 Agent 的差异主要在三点：一是将 rustc 作为 Agent 可调用工具，每
道题必须通过本地三重校验才入库，保证题目机器可解、质量可控；二是引入
“可验证解释评分”——学习者用自然语言解释为何修复有效，Agent 生成若干
探针变体实际编译运行，检验其解释能否预测变体的成败，把“是否真懂”机器
化衡量；三是提供“借用检查器假设实验室”——学习者假设性地修改代码（如
增加生命周期参数），Agent 实际重跑 rustc 并返回诊断增量，使借用规则的
因果可观察。三者都依赖真实本地执行，是通用 Agent 难以做到的。

主要功能：交互式 CLI（选题、做题、实时反馈、长任务可打断）、模型可配置
（endpoint/key/价格/上下文长度，支持 OpenAI 与本地模型）、题目生成与
本地三重校验、错误画像与错题本（带检索）、历史会话存 JSON 可回看、每次
调用的 token 用量与价格统计及预算上限。

选题与课程本身契合：本课程即“边学 Rust 边在 AI 辅助下完成项目”，一个
据错误动态出题并复盘的 Agent 正是即用即学的范式。验证器与语言解耦，未
来可迁移至其他语言，但主线只做 Rust。

期待指正，尤其是错误画像的冷启动与题目质量的客观评估两项。
