## 四、体验基准（参考官方 rustlings 提炼）

1. **场景先行**：题面前两行必须是"这段代码想干什么"（fruit basket /
   soccer table 式的故事），错误与考点由场景自然引出；
2. **tests 即规格**：断言描述可观察行为，不给中间实现暗示；
3. **梯度**：easy=认坑（编译器指路即可修），medium=在 2-3 个合理修法中
   选型或组合两个知识点，hard=重构；
4. **hint 三级不泄底**：方向 → 机制 → 接近签名（M4.8 既有约定）；
5. **一题一心智模型**：title 格式「手法：场景」（现有约定，强制执行）。
