## 二、实机验证结果（真实端点，kimi-k3 @ low，花费 ≈ $0.014）

评审门+复盘**全状态机四路径**均实测通过：

1. **clean**：以参考解通过 → 静态（clippy 具名 lint+行号）→ LLM 评审 clean → quiz
   一次通过口径（"这题考什么"）→ 4 选项（干扰项为真实误解）→ 命中 → 对比表
   （机器五维 + LLM 四维全 5/5，点破"与参考解实质相同"）→ NextConcept。
2. **suggestions → 挑战**：注入 `.clone()`（no-clone 约束）→ 静态违例 + LLM
   finding（"多余堆分配，违背题目提示精神"+具体改法）→ 挑战触发 → [s] 看参考解
   → follow-up = Variant + 附加约束。
3. **suspicious → probe**：注入死代码 `todo!()` → 静态抓残留（+clippy
   items_after_test_module）→ LLM 点名 dead_code_probe → **probe 加测自动生成并
   运行通过** → 怀疑解除，降级 suggestions。
4. **quiz miss → 决策降级**：选错干扰项 → ✗ 未命中 + 正确理解 + 原理解释 →
   follow-up 降为 Variant（换槽位）。

**handback 闭环**：复盘结论带回对话 → 教练调 `list_concepts` → `generate_exercise`
（选题理由合理）→ **M4.10 变式机制自动触发**（borrow_shared_mut_3 槽位轮换）→
教练向用户说明变式。

**R6 分相计费**：`/usage` 明细中 `review`（4 次）/ `debrief`（8 次）/ `chat`
（48 次）独立成相 ✅。

## 三、实机发现并修复的问题

1. **open-loop 检测三个盲区**（§6.3 落地过程中发现）：
   - 粘贴聚合后的 user 消息**不含 ``` 围栏字符**（M4.9 的聚合语义）→ 判定改用
     代码特征启发式（≥3 行 + fn/let/;）；
   - 教练的围栏改写可能隔了多轮追问才出现（思路 → 追问 → 方案）→ 判定窗口从
     "紧邻"放宽为"其后任意 assistant 围栏块，且之后无用户再贴码"；
   - snippet 提取撞上代码块首行空行 → 过滤空行。
2. **模型依从度**：open-loop note 放 system 头部与消息尾部，kimi-k3 均**无视**
   （两次实测）→ 双保险：note 保留（换模型可能有效）+ **CLI 确定性 `↻` 提示行**
   （零成本必然显示："之前贴的代码改动还没验证过——贴回来我帮你跑 check_code"）。
3. UX 小修：clean 且无 findings 时补显 LLM summary（否则像 LLM 层没跑）；
   对比表 LLM 维度从表格改为列表块（长评语不被 26 列宽压扁）。

## 四、决策点（需用户拍板）

| # | 决策 | 我的取值 | 备选与理由 |
|---|---|---|---|
| D1 | **probe 失败路径未实机**（probe 编译失败/测试失败 → 不计掌握） | 单测覆盖解析与运行逻辑，实机只验了"probe 通过解除怀疑" | 可造"LLM 探测必失败"的题实测；价值中等，成本 ~$0.01 |
| D2 | **对比表编译/测试耗时为单次测量**（设计 §4.3 写"多次取中位"） | 单次 | 耗时波动小、感知弱、省时；如要中位改 3 次取中（对比表多 ~2s） |
| D3 | **对比表 LLM 维度用列表块而非表格**（设计写"表格"） | 列表块 | 26 列宽塞不下"短评+具体改法"；已同步设计文档 |
| D4 | **`review_hints` 覆盖率 12/36**（M4.5d 批次一 24 个新模板没有） | 未补 | quiz 干扰项全靠 LLM 造（实测质量尚可）；建议随模板批次二一起补齐（数据活） |
| D5 | **批量 `v` 验证不触发评审门** | 只记状态 | 批量过门会连打 N 次 LLM 且打断节奏；是否要在 v 后提示"共 N 题未评审"？ |
| D6 | **open-loop 模型侧 note 维持还是撤掉** | 维持（换强模型可能生效） | kimi 实测无视；撤掉可省 ~100 tok/回合的注入 |
| D7 | **挑战 [r] 重新评审无次数上限** | 用户可反复 [e]+[r] | 每次重评审 1 次 LLM 调用；是否加上限（如 2 次）？ |
| D8 | **种子 fixtures 完全跳过评审门** | 跳过（无参考解、开发样例） | 若希望 fixtures 也过门，需先给它们补参考解 |
