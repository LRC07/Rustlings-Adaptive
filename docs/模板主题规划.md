## 批量生成流程（届时执行）

1. 按批次写 `templates/<id>.toml`（每主题 1 个；槽位 1–2 个，期望值
   必须由槽位计算而非硬编码；TOML 顶层键必须在 `[[slots]]` 之前）。
2. 更新 fixture 断言数量（`src/template/mod.rs` 的
   `repo_template_library_is_consistent_and_valid`）与 `graph.len()` 下限。
3. `cargo test repo_template_library`：每个模板自动过规则过滤 +
   约束自洽 + 三重校验；红了修模板，不改测试。
4. 更新 README / 设计文档计数；commit 信息 `M4.5-数据: 批次N模板 ×N`。
5. 批次间跑一次真实 `g` 冒烟（覆盖本批主题各挑 1 个）。
6. 批次一可拆成两小批（1–6 / 7–12），与 M4.5 实现并行推进。
